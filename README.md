# ArchiaOS\n\n**ArchiaOS** is an experimental x86-64 operating system built from scratch, with its own UEFI bootloader and kernel.\n\n> **Status:** Early development / experimental\n> **Current focus:** Reliable UEFI -> kernel handoff and validation of the x86-64 kernel foundation.\n\n## Architecture\n\n- x86-64\n- UEFI + GOP\n- ELF64 kernel\n- LLVM/Clang + LLD\n- CMake\n- QEMU + OVMF\n\n## Boot flow\n\n```text\nUEFI\n  |\n  v\nBOOTX64.EFI\n  |\n  +-- locate ESP / kernel\n  +-- validate and load ELF64\n  +-- obtain GOP framebuffer\n  +-- obtain ACPI / SMBIOS addresses\n  +-- obtain final UEFI memory map\n  +-- ExitBootServices()\n  |\n  v\nx86-64 ABI handoff\n  |\n  v\nkernel_entry\n  |\n  v\nkernel_main\n```\n\nThe bootloader uses the Microsoft x64 UEFI calling convention. The handoff translates the kernel call to the SysV AMD64 convention used by the kernel.\n\nUEFI memory-map iteration uses the firmware-provided `DescriptorSize`. If `ExitBootServices()` returns `EFI_INVALID_PARAMETER`, the loader reacquires the memory map and retries immediately.\n\n## BootInfo\n\nThe bootloader and kernel share a versioned `BootInfo` ABI containing the memory map, GOP framebuffer, ACPI/SMBIOS addresses, kernel image range, BootInfo range and bootloader version.\n\nThe kernel validates the magic, version and structure size before consuming the handoff.\n\n## Kernel foundation\n\nThe source tree currently contains implementations for:\n\n- physical memory manager (PMM)\n- bootstrap page-table construction\n- GDT and TSS\n- IDT and exception stubs\n- IRQ infrastructure\n- Local APIC and timer infrastructure\n- ACPI RSDP / RSDT / XSDT / MADT parsing\n\nThese components are being integrated progressively. Their presence in the source tree does not mean that every subsystem is currently exercised during normal boot.\n\n## Current validation\n\nThe development environment is QEMU with OVMF.\n\nThe last manually observed boot, before the current audit changes, reached the bootloader's `BootInfo prepared` message and did not yet produce a confirmed kernel startup sequence. New diagnostics now distinguish memory-map preparation, `ExitBootServices()` and the kernel handoff.\n\n## Memory management\n\nThe PMM starts with all frames reserved and releases only memory types safe for general OS use after `ExitBootServices()`.\n\nIt explicitly reserves the kernel image, BootInfo, the UEFI memory-map buffer, the framebuffer and physical address zero.\n\n## Interrupt architecture\n\nThe x86-64 source contains exception entry stubs, error-code aware frames, early IDT vectors, IST1 Double Fault support, Local APIC initialization, Local APIC timer infrastructure and PIC masking.\n\nI/O APIC routing, IRQ registration and multi-CPU support are not complete.\n\n## Graphics\n\nEarly graphics use UEFI GOP. The bootloader records the framebuffer before `ExitBootServices()` and the kernel performs basic framebuffer validation and drawing.\n\n## Repository layout\n\n```text\nArchiaOS/\n|-- boot/uefi/\n|   |-- include/\n|   `-- x86_64/\n|-- common/boot_info.h\n|-- kernel/x86_64/\n|   |-- core/\n|   |-- cpu/\n|   `-- memory/\n|-- tools/firmware/x86_64/ovmf/\n|-- CMakeLists.txt\n|-- README.md\n`-- .gitignore\n```\n\nGenerated build files belong in `build/` and are excluded from source control.\n\n## Build\n\nInstall LLVM/Clang/LLD, CMake, QEMU and OVMF.\n\n```powershell\ncmake -S . -B build\ncmake --build build --config Release\n```\n\nMain artifacts:\n\n```text\nbuild/BOOTX64.EFI\nbuild/ARCHIAOS_kernel.elf\nbuild/esp/EFI/BOOT/BOOTX64.EFI\nbuild/esp/EFI/ARCHIAOS/ARCHIAOS_kernel.elf\n```\n\n## Development principles\n\n1. Validate firmware-provided structures before using them.\n2. Treat physical-memory ranges as untrusted input.\n3. Keep the bootloader modular.\n4. Keep the bootloader/kernel ABI versioned.\n5. Do not call UEFI Boot Services after successful `ExitBootServices()`.\n6. Keep architecture-specific code isolated.\n7. Test each subsystem in QEMU before treating it as stable.\n\n## Roadmap\n\n### Boot foundation\n- [x] x86-64 UEFI bootloader\n- [x] ELF64 kernel loading\n- [x] GOP discovery\n- [x] ACPI / SMBIOS discovery\n- [x] versioned BootInfo\n- [x] final UEFI memory-map handoff\n- [x] `ExitBootServices()` retry path\n- [ ] fully validated kernel handoff\n- [ ] complete boot-time memory reservations\n\n### Kernel foundation\n- [ ] PMM runtime validation\n- [ ] paging activation and validation\n- [ ] GDT / TSS runtime validation\n- [ ] complete exception handling\n- [ ] Local APIC timer validation\n- [ ] I/O APIC routing\n- [ ] IRQ registration\n- [ ] kernel allocator\n\n### Execution and userspace\n- [ ] processes\n- [ ] threads\n- [ ] scheduler\n- [ ] context switching\n- [ ] IPC\n- [ ] system calls\n- [ ] userspace\n- [ ] graphics subsystem\n- [ ] desktop\n\n### Hardware and compatibility\n- [ ] PCI / PCIe\n- [ ] storage\n- [ ] USB\n- [ ] network\n- [ ] input\n- [ ] audio\n- [ ] power management\n- [ ] native driver framework\n- [ ] Secure Boot integration\n- [ ] signed drivers\n- [ ] Windows compatibility layer\n- [ ] Linux compatibility environment\n\n## License\n\nNo license has been selected yet.
